# Quan Ly The Tin Dung 2026

Web tĩnh phục vụ tra cứu, tư vấn và so sánh sản phẩm thẻ BIDV từ dữ liệu và hình ảnh đang có trong workspace.

## Thành phần chính

- Tra cứu nhanh theo từ khóa nhu cầu khách hàng.
- Gợi ý thẻ phù hợp theo mô tả chân dung khách hàng.
- Danh mục thẻ với bộ lọc phân khúc và nhóm nhu cầu.
- So sánh tối đa 4 sản phẩm trên cùng hệ quy chiếu.
- Khu khuyến mại còn hiệu lực và ghi chú tư vấn.

## Chạy local

```bash
node server.js
```

Mở `http://127.0.0.1:4173`.

## Dữ liệu

- `bidv_card_web_data/cards.json`
- `bidv_card_web_data/details.json`
- `bidv_card_web_data/promotions.json`
- `bidv_card_web_data/services.json`
- `Design thẻ BIDV/*`

## Lưu ý

Thông tin biểu phí, lãi suất và khuyến mại vẫn cần đối chiếu với văn bản hiệu lực của BIDV trước khi tư vấn chính thức.
